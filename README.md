# Creation — Shadertoy XsXXDn 本地复刻

复刻自 Shadertoy 上的经典 shader **[Creation](https://www.shadertoy.com/view/XsXXDn)**，
作者 **Danilo Guanabara（Silexars / Danguafer）**，2011 年 DemOS 竞赛第二名，
被认为是第一个 1kB 的 WebGL intro。原作者在源码中注明：复用请保留署名
（"If you intend to reuse this shader, please add credits to 'Danilo Guanabara'"），
本复刻已保留。

## 怎么运行

方式一（最简单）：直接双击 `index.html` 用浏览器打开即可。

方式二（本地服务器）：

```bash
cd shadertoy-creation
python3 -m http.server 8642
# 浏览器打开 http://127.0.0.1:8642/
```

无任何外部依赖（无纹理、无 CDN、无构建步骤），全部代码在 `index.html` 一个文件里。

## 操作

| 按键/控件 | 功能 |
|------|------|
| 右上角参数面板 | 实时调节画面效果（见下表） |
| 空格 | 暂停 / 继续 |
| R | 重置时间 |
| 按住鼠标拖动 | 向 shader 传入 `iMouse`（本 shader 未使用，但运行器支持） |

### 可调参数

| 参数 | 默认值(=原版) | 说明 |
|------|------|------|
| 播放速度 | 1.00 | 作用于 `iTime`，0 为冻结画面 |
| 画面缩放 | 1.00 | >1 放大图案，<1 缩小 |
| 相位间隔 | 0.070 | RGB 三通道的相位步长，越大色散/彩虹感越强，0 为纯白 |
| 波纹频率 | 9.0 | 径向波纹密度，调高会变成密集波纹隧道 |
| 位移强度 | 1.00 | 图案拉伸形变幅度，0 时收缩为同心圆环 |
| 光点亮度 | 0.010 | 光点辉光亮度 |
| 形状边数 | 圆点 | 0=原版圆点/圆球；3=三角、4=方……12=十二边形 |
| 形状大小 | 0.000 | >0 时光斑变成对应多边形的霓虹描边（3D 下为棱柱/球体），0 保持原版 |
| 形状旋转 | 0° | 多边形的朝向 |
| 晶格间距 | 2.00 | 仅 3D 模式：晶格单元的间距 |

### 渲染维度与颜色

| 参数 | 默认值 | 说明 |
|------|------|------|
| 渲染维度 | 平面 | 平面=原版 2D；3D 空间=raymarching 无限晶格隧道，圆点变球体、多边形变棱柱，相机随时间前进，**按住鼠标拖拽可环绕视角**（R 重置视角） |
| 色相旋转 | 0° | 整体色相偏移，平面/3D 都生效 |
| 彩虹流动 | 0.00 | 颜色随空间与时间流动变化 |

3D 模式沿用原 shader 的屏幕空间涡旋 warp 与 `1/dist` 发光审美：
对每条光线 raymarch 求它到晶格形状的最近距离 `minD`，亮度 `∝ 1/minD²` 并按距离雾化，
色相由余弦调色板按深度生成。平面模式所有参数为默认值时与原版逐像素一致。

面板可点击标题折叠；"🎲 随机"一键随机所有参数（每个参数在各自的安全范围内取随机值，避开画面冻结、全黑等退化组合），"恢复默认"一键还原为原版效果。

## 圣殿小游戏（game.html）

**背单词圣殿**：26 尊白色石膏神明排成弧形合唱队，**每尊对应一个英文字母**
（键盘 A–Z 一键一像，音高按半音阶 C4–D6 排列），天空由 Creation 分形构成。

| 操作 | 效果 |
|------|------|
| 📖 单词试炼 | 核心玩法：随机抽一个雅思词库单词并**用英语朗读** → 按字母键拼写的每个字母让对应神明发光奏音 → **回车提交**；正确显示 ✓ 与中文释义后继续；**拼错则显示 ✗、正确拼写及释义，同一个词清空重拼，直到拼对才进入下一词**（一次拼对才计入正确率）；点击神像等同输入该字母，退格可删 |
| 每 10 词 | 拼写过程中弹过的音符自动编成一首曲子（旋律+和弦垫+回声）播放，期间**循环播报这 10 个单词及释义**复习巩固 |
| 结算 | 圣歌播完后按**一次拼对率**以神圣字体评级（另附误拼次数）：SSS 词汇之神 / SS 过目不忘 / S 出口成章 / A 渐入佳境 / B 稳步积累 / C 再接再厉，回车或点击开始下一轮 |
| 乐谱栏 + ▶ 演奏 | 音游模式：音符从天而降，按键/点击车道消除，圣光/微光/擦过/错过四档判定计分，结束金字体评级 |
| 键盘/点击神像（自由模式） | 弹音、环视（拖拽）、远近（滚轮）、目光之光（移动鼠标） |

朗读使用浏览器语音合成（Web Speech API，en-US），词库内置 80 个雅思高频词。

| 操作 | 效果 |
|------|------|
| 键盘 `A S D F G H J` | 弹低八度 C4–B4（对应 1–7 号神明） |
| 键盘 `Q W E R T Y U` | 弹高八度 C5–B5（对应 8–14 号神明） |
| 点击神像 | 弹出该神明的音 |
| 乐谱栏输入 + ▶ 演奏 | **音游模式**：神明们按序歌唱的同时，发光音符沿各自车道从天而降——在音符落到判定线的瞬间**按对应键盘键或点击该神像的车道**消除它：≤60ms「圣光」1000 分、≤130ms「微光」600 分、≤220ms「擦过」250 分，迟到自动记「错过」；连击加得分。演奏完毕自动结算 |
| **结算** | 金色圣体大字给出评级：SSS 神之共鸣 / SS 圣殿之光 / S 金声玉振 / A 和谐乐章 / B 初窥圣径 / C 尚需修行，伴随神圣和弦结束音，诸神苏醒唱起圣咏作为庆典 |
| **乐谱演奏完毕** | **终章**：升腾音效拉起 → 诸神从低音到高音如音浪般依次苏醒（每尊苏醒时唱出自己的音，与你的旋律自然衔接）→ 头后亮起常驻金色双环圣环（带旋转光辐）→ 全体唱起恢弘圣咏（定音鼓+合唱式失谐和声垫+加长回声+两遍旋律变奏+终止齐鸣）；点 ■ 停止 或 点击任一神像 即回归宁静 |
| 拖拽 / 滚轮 | 环绕视角 / 远近 |
| 移动鼠标 | 目光之光——跟随光标的光源 |

发声时该神明头后闪现光环、身披按音高着色的轮廓光、脚下泛起音之光池；
低音神明唱温暖钟声，高音神明唱明亮钟琴（WebAudio 合成，带回声）。

神像为精修版白色石膏：面部鼻梁与眼窝、佛陀耳垂/白毫/袈裟衣褶、祈祷者兜帽檐/腰带、
女神发髻/项链/冠顶宝珠；材质含 wrap 漫反射+冷色天光+SDF 环境光遮蔽+软阴影。
地面为程序化月下草坪（平滑值噪声），每尊神像脚下有圆形石台。

### 与参数实验室的联动

`index.html` 里调节 **相位间隔 / 波纹频率 / 位移强度 / 光点亮度 / 播放速度 /
色相旋转 / 彩虹流动 / 画面缩放 / 形状边数 / 形状大小 / 形状旋转 / 晶格间距** 时，
参数会通过 localStorage（同源，150ms 防抖）实时推送给 `game.html` 的分形天空：
其中**形状三参数**会直接改变天空光斑的几何形状（实验室设成六边形，圣殿天空就浮现
六边形霓虹描边），缩放/晶格间距改变图案密度，色相/彩虹改变整体色调——圣殿背景
即刻跟随变化，无需刷新；实验室页面重开时会自动恢复上次的调节状态。注意两个页面需
以同一种方式打开（都用本地服务器，或都直接双击），跨方式打开时因浏览器源不同无法同步。

## 实现说明

`index.html` 内置了一个约 100 行的迷你 Shadertoy 运行器：

- WebGL 1 全屏三角形渲染，自动适配窗口尺寸和 devicePixelRatio；
- 预置 Shadertoy 标准 uniforms（`iResolution`、`iTime`、`iTimeDelta`、`iFrame`、
  `iFrameRate`、`iMouse`、`iDate`、`iChannel0..3`），并把用户的 `mainImage`
  包装成 `main()`，与 Shadertoy 官方行为一致；
- shader 源码原样放在 `<script id="shader-main">` 中，未做任何改动，
  可直接替换成其他 Shadertoy shader（只要不依赖特殊输入纹理）。

## Shader 原理（一段话）

对每个像素从时间 `z=t` 开始做 3 次迭代，每轮把极坐标方向的偏移
`p/l·(sin(z)+1)·abs(sin(l·9−z−z))` 叠加到采样坐标 `uv` 上（`l` 是到屏幕中心的距离），
再取 `0.01/length(mod(uv,1)−0.5)` 得到该通道亮度——本质是对径向镜像重复图案
做的一维混沌迭代，RGB 三个通道用略微不同的相位，于是形成彩色放射分形光斑。
